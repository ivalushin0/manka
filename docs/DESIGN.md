# Manka: дизайн-токены и компоненты

Один язык для Android-приложения и PC-версии ([Manka-UI](https://github.com/ivalushin0/Manka-UI)).
Значения ниже совпадают с `D:\Dev\Manka-UI\app\src\app.css`; в Android они живут в
`app/src/main/java/app/manka/ui/theme/Theme.kt`, компоненты — в `ui/Components.kt`.
Макет экранов: `docs/design/index.html`.

Material 3. Так Android и PC выглядят как один продукт.

## Форма и типографика

- Радиус карточки — 16, кнопки — 10, поля — 12, пилюли — 50.
- Отступ внутри карточки — 14–16, между карточками — 10–12.
- Шрифт — системный (Segoe UI на PC, Roboto на Android). Значения и конфиги — моноширинный.
- Заголовок экрана — 19–20/700, подзаголовок — 11–12 `muted`, тело — 14, подсказка — 12–13.

## Компоненты

| Компонент | Где | Правило |
|---|---|---|
| `StatusPill` | везде | Цветная капсула с точкой: «Работает» (ok), «Частично» (warn), «Ошибка» (bad), «Выключено» (muted). |
| `Banner` | Главная, Telegram, Доктор | Тонированный блок с заголовком, текстом и действием. warn — «обрати внимание», bad — «не работает», ok — «всё хорошо». |
| `SectionCard` | везде | Карточка с рамкой 16. Один смысловой блок на карточку. |
| `KeyRow` | Telegram, Доктор | Подпись 84 + значение; значения моноширинным. |
| `FoldCard` | Настройки | Свёрнутая карточка: заголовок и одна строка summary. |

Правила текста: одна основная кнопка на экран; «перезапустить/удалить» — опасная (красная).
Состояние показываем пилюлей, а не только цветом текста.

## Экраны

1. **Главная** — крупная карточка состояния (переключатель, движок, профиль, статистика, две кнопки),
   сетка сервисов, карточки Telegram и прокси приложений.
2. **Telegram** — статус, проверка (`tgws-probe` с выводом ядра), параметры подключения, баннер
   занятого порта 1443, настройки порта и секрета.
3. **Доктор** — root, модуль, движок, DNS, Telegram, прокси приложений, сеть; «Собрать отчёт»
   копирует статус модуля и пробу в буфер.

Остальные экраны (Автоподбор, Магазин, Настройки) приводятся к этой же сетке постепенно: page-head,
карточки с рамкой, баннеры вместо цветных контейнеров.
